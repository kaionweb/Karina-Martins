## Scope Note (decisões registradas nesta preparação)

1. **Endpoint `POST /ai/chat/en` é criado nesta story** — a Story 4.1 (Scope Note item 1) deferiu explicitamente qualquer controller para "Stories 4.2/4.3, que adicionam restrição de tema, seleção de modelo por idioma [...] por cima desta camada". Esta story implementa exatamente essa camada: controller + system prompt restrito + seleção do modelo `claude-haiku-4-5`, reaproveitando o `AiService.sendMessage` já existente sem alterá-lo.
2. **Sem checagem de `AI_DAILY_LIMIT`, sem filtro de conteúdo, sem persistência em `AiSession`/`AiMessage` nesta story.** O diagrama de sequência "Chat de IA em inglês (lição ativa)" (`docs/architecture.md#Chat de IA em inglês`) mostra esses três passos, mas eles pertencem a stories próprias e nomeadas no Epic 4 do PRD: limite diário e registro de tokens = **Story 4.5** ("Limite diário e auditoria de tokens"); filtro de conteúdo pré-persistência = **Story 4.4**. Nenhuma AC desta story (4.2) menciona limite, filtro ou persistência — implementá-los agora seria invenção fora do escopo declarado. O endpoint retorna a resposta da IA diretamente ao chamador, sem gravar nada no banco.
3. **Sem branch de comportamento por `Profile.type` (ADULT vs CHILD).** O JWT access token (`AccessTokenPayload`, `apps/api/src/common/auth/jwt.util.ts`) carrega apenas `sub`/`profileId`, nunca o tipo do perfil — nenhuma story anterior adicionou tipo ao payload. AC1 diz "restrito ao universo/tema da lição ativa (para perfis CHILD)", mas isso descreve o **público-alvo do produto** (só a criança pratica inglês na lição), não uma checagem de runtime exigida por alguma AC. Nenhuma AC pede rejeição de perfis ADULT chamando este endpoint. Não inventado: o endpoint aplica o mesmo system prompt restrito a qualquer perfil autenticado que o chame, exatamente como os demais endpoints protegidos por `JwtAuthGuard` já existentes (`/lessons/:id`, etc.) não distinguem tipo de perfil.
4. **AC2 ("IA recusa e redireciona") é implementada como instrução explícita dentro do system prompt, não como validação pós-resposta.** Mesma limitação já registrada na Story 4.1 (Scope Note item 2): não há chamada real à Anthropic nos testes (sem `ANTHROPIC_API_KEY` local, custo de API paga). O teste verifica que o texto do system prompt enviado ao client (mockado) contém a instrução de recusa/redirecionamento — não que o modelo de fato obedeça (responsabilidade da própria Anthropic, fora do controle deste projeto).
5. **Fonte do "tema da lição" = `Lesson.title` + `Lesson.contentBody`.** São os únicos campos do model `Lesson` (`docs/architecture.md#Show / Track / Lesson`) que descrevem o conteúdo/tema; nenhum campo adicional (ex. "tópicos", "vocabulário") existe no schema atual — não inventado.
6. **`LessonsModule` precisa exportar `LessonsService`.** Hoje (`apps/api/src/modules/lessons/lessons.module.ts`) o service não está em `exports`, então nenhum outro módulo pode injetá-lo. Adicionar o export é a única mudança necessária em `LessonsModule` para reaproveitar `LessonsService.getLesson` (já existe, já lança `NotFoundException` para lição inexistente — reaproveitado sem duplicar lógica).
7. **Novo schema zod `ChatEnSchema` em `packages/shared`**, seguindo o padrão exato de `RegisterSchema`/`LoginSchema` (`packages/shared/src/schemas/auth.schema.ts`): objeto exportado + tipo `ChatEnInput` inferido. Nenhuma AC especifica limite de tamanho da mensagem; `max(2000)` é um valor técnico defensivo (evitar prompt gigante gerando custo/token desnecessário), documentado aqui para a Story 4.5 revisar se precisar de outro limite.
8. **Resposta do endpoint: `{ reply: string }`.** Formato mínimo suficiente para as ACs desta story; a Story 4.5 (que adiciona persistência/auditoria) é responsável por decidir se o formato de resposta muda para incluir `sessionId` ou métricas de tokens.

## Story

**As a** criança,
**I want** conversar em inglês sobre o tema da lição atual,
**so that** posso praticar o idioma de forma guiada.

## Acceptance Criteria

1. System prompt do chat é restrito ao universo/tema da lição ativa (para perfis CHILD)
2. IA recusa e redireciona educadamente para o tema quando a conversa foge do escopo
3. Usa modelo `claude-haiku-4-5`
