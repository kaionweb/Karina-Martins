## Scope Note (decisões registradas nesta preparação)

1. **Mesmas regras de acesso da Story 5.1, extraídas para um método privado compartilhado.** `GET /parent/profiles/{id}/journey` (5.1) e `GET /parent/profiles/{id}/transcripts` (esta story) têm exatamente a mesma checagem de segurança: perfil ativo CHILD bloqueado (403) e perfil-alvo precisa ser CHILD da mesma conta (404, sem diferenciar motivo). Em vez de duplicar essa lógica, `ParentService` ganha `resolveChildProfile(activeUser, targetProfileId)`, reaproveitado por ambos os métodos — refatoração mínima, sem mudar o comportamento já testado da Story 5.1.
2. **Transcrição = `AiSession` + suas `AiMessage`, em ordem cronológica.** AC1 diz "lista transcrições de `AiSession` por perfil CHILD" — cada `AiSession` (Story 4.5) já é uma interação completa (1 pergunta + 1 resposta, ver Story 4.5 Scope Note item 2); a "transcrição" é simplesmente a listagem dessas sessões com suas mensagens, sem transformação adicional.
3. **Resposta inclui `lessonTitle` (não só `lessonId`)** — enriquecimento não-inventado: `AiSession.lessonId` já tem relação direta com `Lesson` no schema (Story 4.5); incluir o título torna a transcrição legível para o responsável ("sobre qual lição foi essa conversa?") sem inventar nenhum dado novo, só seguindo uma relação já existente. `lessonTitle` é `null` quando `lessonId` é `null` (dúvida geral do assistente PT, Story 4.3).
4. **`flaggedByFilter` de cada mensagem é exposto na transcrição** — é exatamente o propósito de transparência da story ("ter total transparência sobre o que ela está falando com a IA"): o responsável precisa saber quando uma resposta foi barrada pelo filtro de conteúdo (Story 4.4), não só ver o texto de fallback sem contexto.
5. **Frontend: rota `/dashboard/transcripts/[profileId]`**, exatamente conforme `docs/architecture.md#Route Organization`. `JourneyCard` (Story 5.1) ganha um link para essa rota — única mudança nesse componente já existente.
6. **Nenhuma paginação/filtro nesta story** — nenhuma AC exige, e o volume de dados de uma demo (`AI_DAILY_LIMIT` default 20/dia) é pequeno o suficiente para listar tudo de uma vez sem paginação. Se o volume crescer, é uma melhoria futura, não desta story.
